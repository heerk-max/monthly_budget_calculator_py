# monthly_budget_calculator_py
# 📊 Monthly Budget Calculator

A friendly Python tool to help you track your monthly income, see where your money goes, and calculate your total savings!

## 🚀 Features

- **Easy Income Tracking:** Quickly log how much money you earn each month.
- **Expense Categorization:** Group your spending (like food, games, and clothes).
- **Instant Math:** Automatically calculates your leftover savings.

## 🛠️ Built With

- **Python 3** - The core programming language.

## 📦 How to Use It

1. Make sure you have **Python** installed on your computer.
2. Download or clone this project to your machine.
3. Open your computer's terminal or command prompt, go to the project folder, and run:
   ```bash
   python calculator.py
   ```

## 📝 Example

```python
# The calculator will ask you simple questions like:
What is your monthly income? \$100
How much did you spend on food? \$10
How much did you spend on rent? \$20

# Then it tells you your leftover savings and income spent:
Your remaining budget is: \$70
Your income spent is:\$30s
```
